# مدیریت اجرا بر اساس نوع پروژه — خط لوله، ایستگاه تقویت فشار گاز، ترکیبی

## تصمیم‌ها (تأییدشده توسط کاربر)
- سه نوع پروژه: **خط لوله** (ایستگاه‌های شیر بین‌راهی، لانچر و رسیور جزو همان است)، **ایستگاه تقویت فشار گاز**، **ترکیبی**.
- ساخت: همان هستهٔ فعلی ماژول اجرا با «حالت ایستگاه» (نه ماژول جدا)؛ گزارش روزانه، تأیید ردیف‌به‌ردیف، صورت‌وضعیت و زنجیرهٔ پرداخت مشترک می‌مانند.
- پروژهٔ ترکیبی: دو محدوده کنار هم، با پیشرفت جدا و پیشرفت کل.
- کنترل کیفیت ایستگاه: ASME B31.8 + IGS.

## فاز ۱ — زیرساخت (انجام شد)
| بخش | تغییر |
|---|---|
| `src/lib/projectProfile.ts` | نوع پروژه (`pipeline` / `compressor_station` / `hybrid`)، خواندن مقدارهای قدیمی متنی («خطوط لوله» → خط لوله)، محدوده‌ها، واژه‌های هر محدوده |
| شناسنامهٔ پروژه | فیلد «نوع پروژه» از متن آزاد به فهرست انتخابی تبدیل شد؛ مقدار قدیمیِ ناشناخته نمایش داده می‌شود و پاک نمی‌شود |
| پایگاه داده (049) | ستون `scope` (pipeline / station) روی `ex_activities` و `ex_reports`؛ NULL = محدودهٔ اصلی پروژه. فقط افزودنی؛ برگشت: `rollback/049_rollback.sql` |
| هستهٔ محاسبه | `executionCore` فقط در پروژهٔ ترکیبی بر اساس محدوده فیلتر می‌کند؛ وزن‌ها درون هر محدوده نرمال می‌شوند؛ پروژهٔ تک‌محدوده همهٔ ردیف‌ها را می‌بیند تا تغییر نوع پروژه هیچ داده‌ای را پنهان نکند |
| ماژول اجرا | انتخاب محدوده در سرصفحه برای ترکیبی («کل پروژه / خط لوله / ایستگاه تقویت فشار»)؛ کارت «پیشرفت به تفکیک محدوده» در داشبورد؛ در محدودهٔ ایستگاه: «ناحیه / واحد» به‌جای جبهه، حذف کیلومتر، اقدام‌های پیش‌فرض ایستگاه، پنهان شدن پروندهٔ جوش کیلومتری |
| ثبت ردیف و گزارش | گزارش و ردیف جدید در پروژهٔ ترکیبی با محدودهٔ نمای جاری ذخیره می‌شود؛ در فهرست فعالیت‌ها ستون و فیلد «محدوده» |
| منوی پروژه | «ایستگاه‌های مسیر (شیر، لانچر، رسیور)»، PipePulse و دوقلوی دیجیتال خط لوله فقط برای خط لوله و ترکیبی |

## فاز ۲ — اجرای ایستگاه (بعدی)
- ثبت لاین، ایزومتریک، اسپول و سرجوش (کارگاهی/میدانی) با واحد اینچ-قطر؛ مراحل برش ← فیت‌آپ ← جوش ← NDT ← رنگ ← ارسال ← نصب ← تست‌پک.
- ثبت تجهیزات (تگ، مراحل نصب، تراز، گروت، هم‌محوری).
- سیویل، راه و محوطه؛ برق و ابزار دقیق.
- سیستم‌ها و تست‌پک‌ها برای پیش‌راه‌اندازی و پیوند با PSSR.

## فاز ۳ — کنترل کیفیت ایستگاه (ASME B31.8 + IGS)
- دامنهٔ NDT ایستگاه (۱۰۰٪)، پذیرش طبق ارجاع B31.8 به API 1104، صلاحیت جوشکار طبق ASME IX.
- ITP سیویل (بتن)، رنگ (DFT)، برق و ابزار دقیق.

## فاز ۴ — دوقلوی دیجیتال ایستگاه
