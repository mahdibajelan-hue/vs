# عملیات، محدودیت‌ها و بازگشت

## وضعیت راه‌اندازی (صادقانه)
| قابلیت | وضعیت |
|---|---|
| اعلان درون‌برنامه + تشدید + مولد زمان‌بندی‌شده | **فعال** (pg_cron هر ۱۵ دقیقه) |
| ایمیل / پیامک / Push / پیام‌رسان | کد و صف آماده؛ **غیرفعال تا ثبت وب‌هوک درگاه**. تا آن زمان `skipped` و در تنظیمات «پیکربندی نشده» دیده می‌شود |
| ارسال زمان‌بندی‌شدهٔ بیرونی | pg_net نصب نیست؛ دکمهٔ «اسکن و ارسال اکنون» (مدیر) یا یک cron بیرونی با `x-cron-secret` |
| هوش مصنوعی مولد | **غیرفعال تا ثبت کلید**؛ دستیار قاعده‌محور (دسته/شدت/استخراج/پرسش/خلاصه/پیش‌بینی) بدون مدل فعال است |
| شباهت/تکراری | واژگانی (توکن + تریگرام) در مرورگر؛ pg_trgm/pgvector نصب نشده → جستجوی معنایی عمیق نیاز به فعال‌سازی دارد |
| ورود/خروج | CSV (UTF‑8 با BOM برای Excel)؛ ورود مستقیم از Excel/XLSX پشتیبانی نمی‌شود |

## محدودیت‌های شناخته‌شده
- مولد اعلان در اولین اجرا برای همهٔ مسائل تأخیردار موجود اعلان می‌سازد (کاتچ‌آپ یک‌بار).
- پیوست‌ها ≤ ۲۰ MB؛ پیش‌نمایش درون‌برنامه‌ای فایل ندارد (دانلود با لینک امضاشده).
- گردش‌کار فقط «استاندارد» است؛ ویرایش گراف از UI فقط‌خواندنی با اعتبارسنجی است (ویرایش از SQL).
- Issue مادر فقط بین پروژه‌های `scope_level` ∈ {program, corporate} و پروژه‌ها پیوند می‌خورد؛ پروژهٔ سطح شرکت باید ساخته و `scope_level` آن تنظیم شود.

## بازگشت (Rollback)
`supabase/issue_mgmt/rollback.sql` اشیای نسخهٔ ۲ را حذف و ستون‌های جدید `im_issues` را برمی‌دارد؛ داده‌های قدیمی (`status`, `deadline_*`, …) دست‌نخورده‌اند. پیش از اجرا از جدول‌های `im_issue_events`, `im_issue_tasks`, `im_decisions` پشتیبان بگیرید (حذف می‌شوند).
