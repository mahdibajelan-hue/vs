# مدیریت ذینفعان

ماژول پروژه‌محور برای شناسایی و تحلیل ذینفعان، برنامه‌ریزی و ثبت تعاملات، و پیگیری نگرانی‌ها و انتظارات آنان. این ماژول در رادار پروژه، گروه «ریسک و مسائل»، قرار دارد.

## اجزا

| بخش | فایل |
|---|---|
| قواعد (ماتریس قدرت و علاقه، فاصلهٔ تعامل، موعد تماس، شاخص فوریت، خلاصه) | `src/modules/stakeholders/lib/stakeholderCore.ts` و آزمون آن |
| خواندن و ثبت داده | `src/modules/stakeholders/store/useStakeholderStore.ts` |
| صفحه | `src/modules/stakeholders/StakeholdersApp.tsx`، `stakeholders.css` |
| پایگاه داده | `supabase/stakeholders/001_stakeholders.sql`، `002_inbox.sql`، بازگشت: `001_stakeholders_down.sql` |

## داده‌ها
- **`sh_stakeholders`**: شناسنامهٔ هر ذینفع، شامل:
  - گروه و نوع (درون‌سازمانی یا برون‌سازمانی)؛
  - قدرت و علاقه (۱ تا ۵)؛
  - نگرش؛
  - سطح تعامل فعلی و مطلوب؛
  - مسئول ارتباط و ایمیل او؛
  - راه ارتباطی و دورهٔ تماس؛
  - انتظارات و راهبرد.

  ذینفع حذف نمی‌شود و فقط بایگانی می‌شود (`is_active`).
- **`sh_engagements`**: تعاملات (جلسه، تماس، نامه، بازدید و…)، همراه با:
  - نتیجه (مثبت، خنثی، منفی)؛
  - اقدام بعدی، با مسئول و مهلت آن و وضعیت انجام.
- **`sh_concerns`**: نگرانی‌ها و انتظارات، با موضوع، اولویت، وضعیت، مسئول، مهلت و پاسخ.
- **دسترسی:** تابع `sh_can_access(project)` تعیین می‌کند چه کسی دسترسی دارد: کاربر باید به پروژه دسترسی داشته باشد و دسترسی ماژول برای او صریحاً بسته نشده باشد. سیاست حذف (DELETE) تعریف نشده است.
- **کارتابل من:** تابع `inbox_my_stakeholder_work()` این موارد را به کارتابل مسئول می‌فرستد:
  - پیگیری‌هایی که مسئولشان کاربر است، از سه روز پیش از مهلت؛
  - نگرانی‌هایی که مسئولشان کاربر است، اگر بحرانی باشند یا تا هفت روز به مهلت مانده باشد.

## قواعد
- **راهبرد:** مقدار ۴ و ۵ «زیاد» به حساب می‌آید. چهار راهبرد عبارت‌اند از:
  - مدیریت نزدیک: قدرت زیاد و علاقهٔ زیاد؛
  - راضی نگه‌داشتن: قدرت زیاد؛
  - مطلع نگه‌داشتن: علاقهٔ زیاد؛
  - پایش: بقیهٔ ذینفعان.
- **فاصلهٔ تعامل:** تعداد پله‌های میان سطح فعلی و سطح مطلوب، روی مقیاس بی‌اطلاع، مقاوم، بی‌طرف، حمایت‌گر و پیشرو.
- **موعد تماس:** وقتی دورهٔ تماس تعریف شده باشد و از آخرین تعامل بیش از آن گذشته باشد (یا هنوز تعاملی ثبت نشده باشد)، موعد تماس رسیده است.
- **شاخص فوریت (۰ تا ۱۰۰):** از این اجزا جمع زده و به ۱۰۰ محدود می‌شود:

  | جزء | امتیاز |
  |---|---|
  | قدرت × علاقه | × ۱٫۶ |
  | نگرش منفی یا مقاوم | ۱۵ |
  | هر پلهٔ فاصلهٔ تعامل | ۸ |
  | هر نگرانی با اولویت زیاد یا بحرانی | ۱۰ |
  | هر پیگیری سررسیدگذشته | ۸ |
  | گذشتن موعد تماس دوره‌ای | ۸ |
  | منفی بودن نتیجهٔ آخرین تعامل | ۸ |

  برای ذینفع بایگانی‌شده، شاخص فوریت صفر است.
