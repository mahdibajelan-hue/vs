# پایش پیشرفت ایزومتریک لوله‌کشی | Piping Isometric Progress Tracker

نرم‌افزار وب حرفه‌ای برای مدیریت و پایش روزانه پیشرفت نقشه‌های ایزومتریک لوله‌کشی در پروژه‌های گاز و پتروشیمی. فایل‌های SVG نقشه ایزومتریک را دریافت می‌کند، امکان ثبت کارکرد روزانه روی هر خط لوله را فراهم می‌سازد و داشبورد مدیریتی، نمودارهای تحلیلی و خروجی‌های حرفه‌ای (PDF / Excel / SVG رنگی) تولید می‌کند.

## پشته فنی

- **React 19 + TypeScript + Vite**
- **Tailwind CSS v4** (تم صنعتی تیره/روشن با افکت Glassmorphism)
- **Zustand** برای مدیریت state + پایداری در `localStorage` (بدون نیاز به بک‌اند)
- **Recharts** برای نمودار S-Curve و گزارش جوشکاری به تفکیک سایز
- **jsPDF + html2canvas** برای خروجی PDF داشبورد تک‌صفحه‌ای (A4 افقی)
- **SheetJS (xlsx)** برای خروجی اکسل
- **lucide-react** برای آیکون‌ها

## اجرای پروژه

```bash
npm install
npm run dev       # اجرای سرور توسعه
npm run build     # ساخت نسخه production در پوشه dist
npm run lint      # بررسی کیفیت کد با oxlint
```

## ویژگی‌های کلیدی

- **آپلود هوشمند SVG**: بارگذاری فایل ایزومتریک، استخراج خودکار المان‌های دارای شناسه (خطوط لوله) و تایید انتخابی قبل از ورود به پروژه.
- **نمای تعاملی نقشه**: زوم با اسکرول موس، جابه‌جایی با درگ، کلیک روی هر خط برای انتخاب و ثبت سریع کارکرد. رنگ‌آمیزی زنده بر اساس وضعیت (تکمیل‌شده / در حال اجرا / اجرا نشده / در حال تست).
- **ثبت کارکرد روزانه**: متراژ، تعداد سرجوش، پاس جوشکاری/تست (ریشه، داغ، پرکننده، نهایی، NDT، هیدروتست)، پیمانکار، توضیحات فنی و علت تاخیر.
- **داشبورد مدیریتی تک‌صفحه‌ای (Executive One-Pager)**: چیدمان اختصاصی A4 افقی شامل نقشه رنگی، کارت‌های KPI، Legend و جدول خلاصه خطوط — آماده خروجی PDF یا چاپ مستقیم مرورگر.
- **گزارش‌های تحلیلی**: نمودار S-Curve (برنامه‌ای در برابر واقعی)، گزارش سرجوش به تفکیک سایز، جدول کارکرد روزانه با فیلتر تاریخ/پیمانکار/وضعیت.
- **خروجی‌ها**: PDF تصویری داشبورد، فایل Excel (خلاصه خطوط + گزارش روزانه)، SVG رنگی‌شده بر اساس وضعیت.
- **چند پروژه‌ای**: مدیریت چند پروژه/ایستگاه به‌صورت مستقل، همراه با داده نمایشی آماده برای شروع سریع.

## معماری کد

```
src/
  types/           تعریف مدل داده (Project, IsoLine, DailyLog, ...)
  store/           Zustand store با پایداری در localStorage
  lib/
    svg.ts         پردازش/استخراج/رنگ‌آمیزی SVG
    progress.ts     محاسبه پیشرفت، KPI، S-Curve، گزارش سایز
    export.ts       خروجی PDF / Excel / SVG (با dynamic import برای کاهش حجم باندل)
  data/            تولید نقشه و داده نمایشی
  components/
    IsoViewer/       نمای تعاملی SVG، لیست خطوط، فرم ثبت کارکرد، مدیریت خطوط
    Dashboard/       کارت‌های KPI
    Reports/         نمودارها و جدول گزارش
    Layout/          Sidebar، Topbar، پروژه جدید
    common/          Modal، Legend، StatusBadge
  pages/            ViewerPage، OnePagerPage، ReportsPage
```

## نکته درباره ذخیره‌سازی

داده‌ها به‌صورت محلی در مرورگر (`localStorage`) ذخیره می‌شوند تا نیازی به راه‌اندازی بک‌اند/دیتابیس نباشد. برای استقرار چندکاربره یا سازمانی، می‌توان لایه store را به یک API واقعی متصل کرد.

## هشدار امنیتی شناخته‌شده

پکیج `xlsx` (SheetJS) دارای دو Advisory شناخته‌شده (Prototype Pollution و ReDoS) بدون نسخه رفع‌شده در npm است. در این پروژه تنها برای **تولید** فایل خروجی اکسل استفاده می‌شود (نه پردازش فایل‌های ورودی نامعتبر)، بنابراین ریسک عملی محدود است.
